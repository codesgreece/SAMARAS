# ΣΑΜΑΡΑΣ Website

Premium corporate website for ΣΑΜΑΡΑΣ — heating, boilers, energy systems and mechanical engineering services since 1945.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `src/app` — routes / pages
- `src/components` — layout, homepage sections, product template, UI
- `src/data` — navigation, products, timeline, services
- `public/brand` — logo assets

## Notes

- Product images and technical specs use replaceable placeholders.
- Contact form is demo-only until backend wiring is added.
- Contact details in the footer/contact page are placeholders.
